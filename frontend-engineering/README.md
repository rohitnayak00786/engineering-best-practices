# Frontend Engineering Best Practices

This is a self-contained, copy-ready coding-agent ruleset.

## Installation
Copy **everything inside this folder** to the **root of your target project**. Then tell your agent: `Read AGENTS.md and follow it for every change.`

## Files
- `AGENTS.md`: main agent entry point
- `CLAUDE.md`: Claude Code entry point
- `best-practices/`: simple coding rules, frontend engineering practices, testing, security and agent workflow
- `docs/changes/`: concise history of meaningful changes and decisions
- `USER_GUIDE.md`: plain-English explanation for teammates

Git records **what** changed; the notes explain **why**. Not every tiny fix needs a history note. Human review is still essential.
