# Frontend Engineering Practices
- Reuse established components, styles, design tokens and state-management patterns.
- Preserve accessibility: labels, keyboard focus, semantic controls and meaningful feedback.
- Use type-safe props/data contracts where possible, and validate external API assumptions.
- Handle loading, empty and error states relevant to the change.
- Avoid unnecessary effects, global state, dependencies or premature performance tweaks.
- Check responsive behavior, regression-prone UI flows and key interactions.
