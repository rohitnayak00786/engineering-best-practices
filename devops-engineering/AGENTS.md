# DevOps Engineering Agent Instructions
1. Read best-practices/coding.md, best-practices/agent-workflow.md, and best-practices/devops-engineering.md.
2. Follow best-practices/testing.md and best-practices/security.md as applicable.
3. Inspect current code, Git status, docs/changes/INDEX.md and relevant notes before modifying existing behavior.
4. Make the smallest safe change and preserve existing conventions and interfaces.
5. Run relevant available checks, report exact results, and flag unverified risks.
6. After a meaningful task, record **what/why/tests/next steps** in docs/changes/ per agent-workflow.md.
7. Current code and Git history take precedence over stale notes. Do not modify production without explicit permission.
